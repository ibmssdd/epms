# EPMS Flutter UI Starter

This is the first static UI pass based on the approved EPMS light-theme reference.

Included:
- Flutter + Dart
- responsive tablet/phone layout
- 16:10 landscape-friendly shell
- independently collapsible left navigation
- independently collapsible right information panel
- welcome dashboard
- today's workflow and tasks
- milestone tasks
- current chapter progress
- syllabus completion
- light/dark theme foundation
